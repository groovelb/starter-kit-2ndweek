# Image Policy Detail

## 이미지 표시 규칙

### 원본 비율 유지
- 모든 이미지: `width: 100%`, `height: auto`, `display: block`
- `object-fit: cover` / `contain`으로 컨테이너에 억지로 맞추지 않음
- 이미지 비율과 컨테이너 비율이 다르면 → 이미지 소스 자체를 올바른 비율로 재생성

### 그리드 높이 매칭
- 같은 행의 이미지 높이를 맞추려면 수학적으로 비율을 역산하여 소스 이미지를 생성
- 예시: 8:4 그리드에서 우측이 56:75(portrait)이면 → 좌측은 112:75 필요 → API 근사 비율 3:2 사용 (~0.45% 차이)

## Gemini API 이미지 생성

### 지원 비율 (Nano Banana 2)
`1:1, 1:4, 1:8, 2:3, 3:2, 3:4, 4:1, 4:3, 4:5, 5:4, 8:1, 9:16, 16:9, 21:9`

### 비율 선택 프로세스
1. 그리드 배치에서 필요한 수학적 비율 계산
2. 지원 비율 중 가장 근사한 것 선택
3. 실제 픽셀 차이 계산하여 허용 범위(~2-3px) 내 확인

### 파일 규칙
| 유형 | 디렉토리 | 네이밍 |
|------|---------|--------|
| 제품 이미지 | `src/assets/product/` | `{id}.png` (Day), `{id}-1.png` (Night) |
| 무드보드 이미지 | `src/assets/brand-mood/` | `{name}.png` (Day), `{name}-night.png` (Night) |

## 무드보드 이미지 구도

### Hero 랜드스케이프 (8/12 컬럼)
- 비율: 3:2 (출력: ~2048×1365)
- 좌측 상단: 완전히 빈 벽 (타이틀 오버레이 겹침 영역)
- 인물+제품: 우측 중앙~하단 배치
- 배경: 완전 평평한 단일 면, 코너/단차/구조물 없음
- 천장: 프레임 내 보이지 않을 정도로 높게

### Portrait 무드보드 (4/12 컬럼)
- 비율: 3:4 (출력: ~1792×2400, 실제 56:75)
