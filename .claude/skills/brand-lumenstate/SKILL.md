# Lumenstate 브랜드 정책

## 핵심 규칙
1. **4색 팔레트만 사용** — `#F5F2EE`, `#F2E9DA`, `#12100E`, `#FFC66E`. 그래디언트/글로우/블러 금지
2. **타임라인 0-1** — 12pm(정오)→12am(자정), 0.5 경계에서 라이트→다크 전환
3. **폰트** — Display: Cormorant Garamond / Body: Pretendard Variable / Icon: lucide-react
